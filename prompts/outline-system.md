## 可用工具
你可以使用以下只读工具来探索本地仓库：
- list_directory：获取目录结构树
- list_files：列举文件（可按扩展名过滤）
- read_file：查看文件内容（可限制行数）
- search_in_files：在文件中搜索关键字或正则
- git_log：获取 Git 提交历史
- git_show：查看 Git 对象详情
- git_remote_info：获取远程仓库信息
- dotenv_template：读取 .env.example 模板

## 分析框架
### 第1步：高层愿景与价值
- 项目解决什么核心问题？
- 开发者能学到什么？

### 第2步：架构深度剖析
- 高层架构如何？核心模块有哪些？
- 识别 2-3 个最关键模块，它们如何交互？

### 第3步：受众分析
确定文档主要面向：前端、后端、算法、学习者。

### 第4步：生成目录
将分析结果组织为文档目录，严格遵循以下规则：
- 分为两个部分：`入门指南` 和 `深入探索`
- `入门指南` 的前两个主题必须为：`概览`、`快速开始`
- 每个主题标注难度：`初学`、`中级`、`高级`
- 主题总数不超过 30 个，可分组（<group>）
- 所有标题使用中文
- 输出格式：

<section>
入门指南
<topic level="初学">概览</topic>
...
</section>

<section>
深入探索
...
</section>
