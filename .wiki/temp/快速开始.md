# 快速开始

5 分钟内，从一个空终端变成一份结构化的代码 Wiki。你需要准备：**Node.js >= 18**、一个 **Git 仓库**，以及一个 **LLM API Key**（如 OpenAI、DeepSeek、Claude 等）。

---

## 第 1 步：安装

```bash
npm install -g wiki-cli
```

安装完成后验证版本：

```bash
wiki-cli --version
```

预期输出：

```
1.0.0
```

如果遇到权限问题（Linux/macOS），加 `sudo`：

```bash
sudo npm install -g wiki-cli
```

[来源](package.json#L2-L4)

---

## 第 2 步：配置 LLM

```bash
wiki-cli config
```

这是你需要做的**唯一一次配置**。CLI 会弹出一系列交互式问题，引导你完成设置。

### 第 2.1 步：选择配置项目

```
? What do you want to configure? (Use arrow keys)
❯ LLM (provider / model / API key)
  Embedding (semantic search model)
  Web Fetch (let AI read documentation URLs)
  Repos Directory (where to store cloned repos)
  Both
  Done, quit
```

选 **Both** 或 **LLM**。Embedding 是可选的语义搜索功能，后面可以随时加。具体各项配置含义见 [配置文件详解](配置文件详解.md)。

[来源](src/commands/config.ts#L37-L62)

### 第 2.2 步：选择 Provider

```
? Select LLM provider: (Use arrow keys)
❯ OpenAI
  Google Gemini
  Anthropic
  xAI Grok
  DeepSeek
  Kimi (Moonshot)
  Mistral
  ✏️  Custom (enter manually)
```

方向键选择你的模型提供商。内置了 7 家主流 Provider，选 **Custom** 可手动输入 Base URL 和模型名，兼容任何 OpenAI 格式的 API。[来源](src/commands/config.ts#L98-L113)

### 第 2.3 步：选择模型

选定 Provider 后会列出该厂商的推荐模型及定价提示：

```
? Select model for DeepSeek: (Use arrow keys)
❯ deepseek-v4-pro - DeepSeek V4 Pro (High quality, competitive price)
  deepseek-v4-flash - DeepSeek V4 Flash (Fast, cost-effective)
```

模型名称、Base URL 和定价信息来自内置的 `default-models.json`。[来源](src/config/default-models.json)

### 第 2.4 步：输入 API Key

```
? Enter API Key: [***********]
```

输入你的 API Key，输入时不会明文显示。安全放心——配置保存在 `~/.wiki-cli/config.json`，只有你能看到。[来源](src/commands/config.ts#L126-L128)

### 第 2.5 步：设置文档语言

```
? Documentation language (zh/en, default zh): zh
```

输入 `zh` 生成中文 Wiki，`en` 生成英文。

### 配置完成

每步完成后 CLI 会打印：

```
✔ Configuration saved to C:\Users\你的用户名\.wiki-cli\config.json
```

以后在任何仓库里运行 `wiki-cli generate`，都会自动读取这份配置。[来源](src/config/config-store.ts#L47-L51)

### 🚀 跳过交互，一把梭

如果你已经清楚自己的配置，可以用命令行参数一步完成：

```bash
wiki-cli config \
  --provider DeepSeek \
  --model deepseek-v4-flash \
  --api-key sk-your-key-here \
  --lang zh
```

支持的全部参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| `--provider` | LLM 提供商 | `DeepSeek`、`OpenAI`、`Anthropic` |
| `--base-url` | API 基础地址（Custom 时必填） | `https://api.deepseek.com` |
| `--model` | 模型名称 | `deepseek-v4-flash` |
| `--api-key` | API 密钥 | `sk-xxxxxx` |
| `--lang` | 文档语言 | `zh` 或 `en` |
| `--llm-only` | 只配 LLM（跳过 Embedding） | 无参数值 |
| `--embedding-only` | 只配 Embedding | 无参数值 |

[来源](src/cli.ts#L18-L33)

## 第 3 步：进入一个 Git 仓库

`wiki-cli` 需要读取仓库的代码结构和 Git 历史来生成文档。CD 到任意 Git 仓库：

```bash
cd /path/to/your/project
```

确认这是一个 Git 仓库：

```bash
git status
```

也可以直接生成远程仓库（无需先 clone）：

```bash
wiki-cli generate --url https://github.com/user/repo.git
```

CLI 会自动 clone 到缓存目录并生成。[来源](src/commands/generate.ts#L33-L38)

---

## 第 4 步：生成 Wiki

```bash
wiki-cli generate
```

### 发生了什么？

生成分**两个阶段**进行：

```
Phase 1: 分析仓库 — LLM 生成大纲（JSON）
Phase 2: 逐个生成每个 Wiki 页面
```

**Phase 1** 中你会看到 LLM 实时流式输出代码分析过程：

```
ℹ Phase 1: Analyzing repository and generating outline...
ℹ Phase 1 / Round 1 (streaming below)...
```

AI 会读取你的源码目录结构、关键文件，梳理出架构脉络，输出一个 JSON 大纲。

**Phase 2** 开始前会问你是否需要并行：

```
? Generate pages in parallel? (faster, no streaming output) (y/N)
```

- 选 **N**（默认）：逐个生成，每个页面都能看到 LLM 的"思考"过程，适合第一次跑想了解质量
- 选 **Y**：并发生成，速度快 3–5 倍，适合已经有信心的时候

[来源](src/commands/generate.ts#L108-L133)

### 生成完成

```
✔ Wiki generated at /path/to/project/.wiki/2025-03-21T10-30-00-000Z
✔ Index file generated.

? Wiki 已生成于 ...，打开浏览器查看？(Y/n)
```

按回车确认，自动跳转到下一步。

---

## 第 5 步：浏览 Wiki

```bash
wiki-cli browse
```

如果不在项目目录，也可以指定路径：

```bash
wiki-cli browse --path /path/to/project
```

### 浏览界面

内置 HTTP 服务器会启动并在浏览器中打开。你看到的是：

- **左侧导航栏**：按模块（section）分组的页面列表，带难度标记（🟢 初级 / 🟡 中级 / 🔴 高级）
- **右侧内容区**：渲染后的 Markdown，代码块自动语法高亮
- **来源链接**：页面中每个引用的代码位置都带 `[来源](src/foo.ts#L12-L34)` 链接，点击直接跳转到源码查看（行号高亮）
- **Mermaid 图表**：架构图中如果包含 Mermaid 语法，会自动渲染为流程图
- **顶部版本切换**：同一项目的多个 Wiki 版本可以通过下拉切换历史快照

[来源](src/commands/browse.ts#L1-L45)

### 更多浏览选项

```bash
# 查看远程仓库缓存的 Wiki
wiki-cli browse --url https://github.com/user/repo.git

# 指定 Wiki 目录
wiki-cli browse --path /path/to/.wiki/2025-03-21T10-30-00-000Z
```

关于浏览器的更多功能（AI 聊天面板、版本对比等），参见 [浏览 Wiki](浏览-wiki.md)。

---

## 完整体验，一行搞定

如果你赶时间，从零到浏览可以压缩成一条命令：

```bash
wiki-cli config --provider DeepSeek --model deepseek-v4-flash --api-key sk-xxx --lang zh \
  && cd /path/to/git/repo \
  && wiki-cli generate --parallel --browse
```
