# 快速开始

5 分钟内，从安装到在浏览器中浏览一份由 AI 自动生成的代码仓库 Wiki。你只需要一个终端、一个 API Key，和一行命令。

---

## 概览

`wiki-cli` 是一个 Node.js 命令行工具，它利用大语言模型（LLM）自动分析你的本地代码仓库，生成结构化的 Wiki 文档。整个过程分为四步：安装工具 → 配置 LLM → 生成文档 → 本地浏览。

如果你还不了解项目的整体定位，可以先阅读 [概览](概览.md)。

[来源](../README.md#L4-L18)

---

## 第一步：安装

确保你已安装 **Node.js >= 18**，然后在终端中执行：

```bash
npm install -g wiki-cli
```

安装完成后，验证是否成功：

```bash
wiki-cli --version
```

你应该会看到版本号输出（例如 `1.0.0`）。如果你不想全局安装，也可以直接用 `npx` 运行：

```bash
npx wiki-cli --help
```

`npx` 方式无需安装，但每次都会从 npm 远程下载，会有短暂延迟。更多安装方式见 [安装与配置详解](安装与配置详解.md)。

[来源](../package.json#L22-L24)
[来源](../README.md#L20-L27)

## 第二步：配置 LLM（首次运行必需的步骤）

安装完成后，**不要直接执行 `generate`**——你需要先告诉工具用哪个大模型。执行：

```bash
wiki-cli config
```

这时终端会进入一个**交互式向导**，你会依次看到以下提示：

### 选择提供商

```
? Select LLM provider: (Use arrow keys)
❯ OpenAI
  Google Gemini
  Anthropic
  xAI Grok
  DeepSeek
  Kimi (Moonshot)
  Mistral
  ✏️  Custom (enter manually)
```

使用上下箭头键选择、回车确认。如果列表中的 7 个内置提供商都不符合你的需求，选择底部 `Custom` 选项手动填写 API 地址和模型名。完整的提供商与模型列表见 [支持的LLM提供商一览](支持的llm提供商一览.md)。

### 选择模型

选定提供商后，会进一步列出该厂商下的可用模型及定价提示：

```
? Select model for DeepSeek: (Use arrow keys)
❯ deepseek-v4-pro - DeepSeek V4 Pro (High quality, competitive price)
  deepseek-v4-flash - DeepSeek V4 Flash (Fast, cost-effective)
```

每个模型都附带了简短描述和价格参考，方便你在质量和成本之间做选择。

[来源](../src/commands/config.ts#L29-L60)
[来源](../src/config/default-models.json#L1-L21)

### 输入 API Key

```
? Enter API Key: ****
```

输入时内容会被 `*` 号遮挡，防止旁人窥屏。如果你之前配置过，向导会默认继承上一次的 Key。

### JSON 输出模式确认

如果工具无法确定你选的提供商是否支持 JSON 输出模式，会询问：

```
? Does this provider support JSON output mode (response_format: json_object)? (Y/n)
```

内置支持 JSON mode 的提供商包括 OpenAI、DeepSeek、xAI Grok、Mistral、Kimi，这些会自动判定，无需手动确认。

[来源](../src/config/config-store.ts#L22-L30)

### 设置文档语言

```
? Documentation language (zh/en, default zh):
```

输入 `zh` 表示中文文档，`en` 表示英文文档。默认值为中文。

### 配置完成

所有步骤完成后你会看到绿色提示：

```
✔ Configuration saved to C:\Users\你的用户名\.wiki-cli\config.json
```

配置会以 JSON 格式持久化存储在 `~/.wiki-cli/config.json` 中，内容类似：

```json
{
  "provider": "DeepSeek",
  "baseUrl": "https://api.deepseek.com",
  "model": "deepseek-v4-flash",
  "apiKey": "sk-xxxxxxxxxxxxxxxx",
  "lang": "zh"
}
```

如果你熟悉参数，也可以跳过交互式向导，直接用命令行参数一键配置：

```bash
wiki-cli config --provider DeepSeek --model deepseek-v4-flash --api-key sk-your-key --lang zh
```

配置文件的存储机制详见 [配置持久化与模型注册表](配置持久化与模型注册表.md)。

[来源](../src/commands/config.ts#L76-L88)
[来源](../src/config/config-store.ts#L32-L40)

## 第三步：生成 Wiki

配置完成后，**在你要生成文档的仓库根目录下**执行：

```bash
wiki-cli generate
```

这是最核心的一步，工具会经历两个阶段。

### 阶段一：生成大纲

终端首先输出：

```
ℹ Phase 1: Analyzing repository and generating outline...
```

工具会调用 LLM 分析仓库结构，你会在屏幕上看到流式的文本输出。LLM 会自主调用系列工具函数来探索代码——包括列出目录、读取文件、搜索关键字等。每个工具调用都会以彩色标签显示在终端上：

```
🔧 Tool: list_directory {"path": "src"}
  ↳ Result: ["cli.ts", "commands", "ai", "utils", "config", ...]
🔧 Tool: read_file {"path": "package.json"}
  ↳ Result: {"name":"wiki-cli","version":"1.0.0",...}
```

这些工具调用是只读的，不会修改你的代码。详见 [工具调用与Agent循环](工具调用与agent循环.md)。

当 LLM 分析完毕，会输出一个 JSON 格式的大纲。成功解析后你会看到：

```
✔ Generated 15 topics.
```

[来源](../src/commands/generate.ts#L47-L86)

### 阶段二：生成页面

大纲生成后，工具会问你：

```
? Generate pages in parallel? (faster, no streaming output) (y/N)
```

- 选 **否**（默认）：逐页串行生成，每页的 LLM 响应会**流式显示**在终端上，你可以实时看到文档内容如何逐字输出，适合调试和观赏。
- 选 **是**（并行）：会进一步询问并发数（默认 3），多页同时生成，速度更快但没有流式输出。

在串行模式下，你会看到类似这样的输出：

```
[1/15] Generating: 快速开始 (初学)
...（LLM 逐字流式输出文档内容）...
✔ Generated: 快速开始
[2/15] Generating: 安装与配置详解 (中级)
...（LLM 逐字流式输出文档内容）...
✔ Generated: 安装与配置详解
```

如果生成过程中断（比如网络问题或你按了 Ctrl+C），重新运行 `wiki-cli generate` 会检测到临时数据：

```
? Previous generation temp data found. What do you want to do?
❯ 🔄 Resume from last checkpoint
  🗑️  Discard and start fresh
```

选择「Resume from last checkpoint」即可从断点恢复。详见 [断点续传与失败重试](断点续传与失败重试.md)。

[来源](../src/commands/generate.ts#L88-L120)

### 生成完成

所有页面生成后，你会看到：

```
✔ Wiki generated at .wiki/20250101_120305
✔ Index file generated.
```

生成的文档存储在仓库根目录的 `.wiki/<时间戳>/` 文件夹下，每个页面是一个独立的 Markdown 文件。

## 第四步：浏览 Wiki

执行：

```bash
wiki-cli browse
```

工具会自动在本地启动一个 HTTP 服务器，并**自动打开默认浏览器**，你会看到类似这样的深色主题界面：

```
┌─────────────────────────────────────────────────────────┐
│ 📖 Wiki                          │                       │
│                                  │                       │
│ 🟢 概览                           │ # 快速开始            │
│ 🟢 快速开始                        │                       │
│ 🟡 安装与配置详解                    │ 5 分钟内，从安装到在   │
│ 🟡 支持的LLM提供商一览                │ 浏览器中浏览...      │
│ 🟡 命令行参考手册                    │                       │
│ 🔴 项目结构与模块职责                  │ 代码块和表格自动高亮   │
│ 🔴 命令调度与生命周期                  │ 显示...              │
│ ...                               │                       │
└─────────────────────────────────────────────────────────┘
```

界面特点：

- **左侧边栏**：展示所有页面，按章节分组。难度等级用彩色圆点标识——🟢 初学、🟡 中级、🔴 高级。点击任意页面标题，右侧内容区会**无刷新加载**对应内容，无需重新加载页面。
- **右侧内容区**：使用 GitHub 深色主题（`#0d1117` 背景），Markdown 内容实时渲染。代码块使用 highlight.js 实现语法高亮。
- **源码引用链接**：Wiki 中引用代码源文件的地方，会显示 `[来源]` 按钮，点击在新标签页查看原始源码。
- **路由分发**：服务器支持页面 API（`/api/page/`）、源码 API（`/api/source/`）和 `.md` 重定向等多条路由。

详细的浏览体验与 UI 交互见 [浏览生成的Wiki](浏览生成的wiki.md)，服务器实现原理见 [HTTP服务器与路由分发](http服务器与路由分发.md)。
