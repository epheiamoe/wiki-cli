# 安装与配置详解

## 两种运行方式：全局安装 vs npx

wiki-cli 是一个 **Node.js CLI 工具**，最低要求 Node.js >= 18。你可以通过两种方式运行它。

### 方式一：全局安装（推荐）

```bash
npm install -g wiki-cli
```

全局安装后，`wiki-cli` 命令会添加到系统 PATH 中，后续使用只需直接敲命令：

```bash
wiki-cli --help
```

安装的依据来自 `package.json` 中的 `bin` 字段，它将 `wiki-cli` 命令指向编译后的入口文件 `dist/cli.js`。

```json
{
  "bin": {
    "wiki-cli": "dist/cli.js"
  }
}
```

[来源](package.json#L6-L8)

### 方式二：npx 免安装运行

如果你只想尝鲜，或者不想污染全局环境，可以用 **npx** 直接运行：

```bash
npx wiki-cli --help
```

npx 会自动从 npm  registry 下载包并执行，执行完毕后缓存到本地（下次再跑就用缓存了）。两种方式在使用上没有区别，所有命令和参数完全一致。

### 检查安装是否成功

任意方式运行后，看到帮助信息即表示安装成功：

```bash
wiki-cli --help
# 或
npx wiki-cli --help
```

如果你还未接触过 wiki-cli 的完整流程，建议先阅读 [](概览.md) 了解整体工作原理，再跟着 [](快速开始.md) 走一遍端到端流程。

## 交互式配置向导

在生成文档之前，你需要告诉 wiki-cli **使用哪个 LLM、哪个模型、以及你的 API Key**。运行以下命令进入交互式配置：

```bash
wiki-cli config
```

配置向导会依次引导你完成以下 5 个步骤：

### 步骤 1：选择 LLM 提供商

你会在终端看到一个列表，内置了 **7 个 LLM 提供商** 供你选择：

- OpenAI
- Google Gemini
- Anthropic
- xAI Grok
- DeepSeek
- Kimi (Moonshot)
- Mistral

如果列表中没有你想要的提供商（比如你使用某个兼容 OpenAI API 的自建服务），还可以选择 **"✏️ Custom (enter manually)"** 手动输入 Base URL 和模型名称。

[来源](src/commands/config.ts#L22-L36)

> 完整的提供商与模型列表见 [](支持的llm提供商一览.md)。

### 步骤 2：选择模型

选定提供商后，第二步会展示该提供商下的所有可用模型，每个模型附带简要描述和价格提示（如 "Fast, low cost"），帮助你做选择。

例如选择 DeepSeek 后，你会看到：

```
? Select model for DeepSeek:
  deepseek-v4-pro - DeepSeek V4 Pro (High quality, competitive price)
❯ deepseek-v4-flash - DeepSeek V4 Flash (Fast, cost-effective)
```

[来源](src/commands/config.ts#L39-L52)

### 步骤 3：输入 API Key

你的 API Key 会以 **密码模式** 输入（输入时显示为 `*`），不会被旁人看到。如果你之前已经配置过，它会自动填入上次的值作为默认值。

[来源](src/commands/config.ts#L68-L76)

### 步骤 4：配置 JSON mode 确认

wiki-cli 依赖 LLM 的 **JSON 输出模式** 来保证生成结构化大纲。对于已知支持 JSON mode 的提供商（OpenAI、DeepSeek、xAI Grok、Mistral、Kimi），系统会自动启用，不会询问。对于自定义提供商，系统会询问你：

```
? Does this provider support JSON output mode (response_format: json_object)? (Y/n)
```

如果你不确定，建议选 **Yes**（大多数兼容 OpenAI API 的服务都支持）。

[来源](src/commands/config.ts#L80-L91)

### 步骤 5：选择文档语言

最后一步，输入你希望生成的 Wiki 文档语言：

- `zh` — 中文（默认）
- `en` — English

你可以直接回车使用默认值。

[来源](src/commands/config.ts#L93-L99)

### 配置完成

所有步骤完成后，配置会保存到磁盘，控制台会打印确认信息：

```
✔ Configuration saved to C:\Users\YourName\.wiki-cli\config.json
```

[来源](src/commands/config.ts#L103-L104)

## 命令行参数快捷配置

如果你不想经历交互式问答，可以 **一次性通过命令行参数完成配置**。当下列四个参数**同时**提供时，配置向导会跳过所有交互步骤，直接保存：

```bash
wiki-cli config \
  --provider DeepSeek \
  --model deepseek-v4-flash \
  --api-key sk-your-key-here \
  --lang zh
```

支持的参数如下：

| 参数 | 说明 | 示例 |
|------|------|------|
| `--provider` | LLM 提供商名称 | `DeepSeek` |
| `--base-url` | API 基础地址（自定义必填） | `https://api.deepseek.com` |
| `--model` | 模型名称 | `deepseek-v4-flash` |
| `--api-key` | API Key | `sk-xxxx` |
| `--lang` | 文档语言 | `zh` 或 `en` |

**判断逻辑**：当 `--api-key`、`--base-url`、`--model`、`--provider` **四个参数同时存在**时，直接保存并退出，不进入交互模式。如果缺少任何一个，则回退到交互式向导。

[来源](src/commands/config.ts#L11-L19)

> 更多命令选项请参考 [](命令行参考手册.md)。

## 配置文件存储位置

配置持久化在用户主目录下的 `.wiki-cli/config.json` 文件中。不同系统的路径如下：

| 系统 | 路径 |
|------|------|
| Windows | `C:\Users\<你的用户名>\.wiki-cli\config.json` |
| macOS | `/Users/<你的用户名>/.wiki-cli/config.json` |
| Linux | `/home/<你的用户名>/.wiki-cli/config.json` |

文件内容是一个标准的 JSON 对象，例如：

```json
{
  "provider": "DeepSeek",
  "baseUrl": "https://api.deepseek.com",
  "model": "deepseek-v4-flash",
  "apiKey": "sk-your-key-here",
  "lang": "zh",
  "jsonMode": true
}
```

你可以**直接编辑这个文件**来修改配置（但再次运行 `wiki-cli config` 会更安全，避免格式错误）。如果你更换了 LLM 提供商，也只需重新运行 `wiki-cli config` 重新设置即可。

[来源](src/config/config-store.ts#L16-L17)

> 关于配置系统的底层实现（文件读写、JSON Schema、模型注册表），详见 [](配置持久化与模型注册表.md)。
