# 概览

**wiki-cli** 是一个命令行工具，它的核心能力只有一句话：**用 LLM 自动为任意本地代码仓库生成结构化的 Wiki 文档**。你只需在项目根目录下依次执行三条命令，就能获得一个带有侧边栏导航的完整技术 Wiki。

## 三条命令，三种职责

| 命令 | 职责 | 关键行为 |
|------|------|----------|
| `wiki-cli config` | 配置 LLM 提供商、模型、API Key 和文档语言 | 交互式向导 + 命令行参数快捷配置 |
| `wiki-cli generate` | 分析当前仓库并生成 Wiki 文档 | 两阶段生成流程（大纲→页面），支持断点续传 |
| `wiki-cli browse` | 在浏览器中预览已生成的 Wiki | 启动本地 HTTP 服务器，渲染 Markdown + 侧边栏 |

[来源](../src/cli.ts#L12-L49)

## 两阶段生成流程

生成过程分为两个清晰的阶段：

1. **大纲生成**——LLM 通过工具调用自主探索仓库目录、读取关键文件、搜索代码模式，理解项目结构后输出 JSON 格式的文档大纲。
2. **页面生成**——基于大纲逐页生成 Markdown 文档，支持串行（流式输出）和并行（多并发）两种模式，失败页面可自动重试。

[来源](../src/commands/generate.ts#L50-L81)

## Agent 式工具调用的设计理念

项目没有让 LLM "凭空编写"，而是赋予它 7 个**只读代码分析工具**（如 `list_directory`、`read_file`、`search_in_files`、`git_log` 等），让 LLM 像一名开发者一样，通过多轮对话循环自主探索仓库，再基于真实代码生成文档。这种 Agent 模式保证了文档的准确性和深度。
