# wiki-cli 概览

## 项目定位

**wiki-cli** 是一个命令行工具，能自动分析本地代码仓库的结构，借助 **大语言模型（LLM）** 生成结构化的 Wiki 文档。你不需要手动写文档——只需一条命令，工具会帮你完成从代码分析到文档生成再到本地浏览的全过程。

项目只有一个核心依赖——[Commander.js](https://github.com/tj/commander.js) 负责 CLI 框架，所有"文档怎么写"的智能决策都交由 LLM 来完成。

```
用户输入 wiki-cli generate → 工具分析仓库结构 → LLM 生成大纲 → LLM 逐页生成内容 → 输出 .wiki/ 目录
```

## 四条命令

工具暴露四个子命令，覆盖了从配置到消费的完整链路。以下是它们的功能与参数对比：

| 命令 | 一句话功能 | 核心参数 | 典型用法 |
|---|---|---|---|
| `config` | 设置 LLM 提供商、模型、API Key 和文档语言 | `--provider`, `--model`, `--api-key`, `--lang`, `--base-url` | `wiki-cli config --provider DeepSeek --model deepseek-v4-flash` |
| `generate` | 分析仓库并生成 Wiki 文档 | `-C/--dir`, `-u/--url`, `-p/--parallel`, `-c/--concurrency`, `-r/--retry`, `-s/--silent` | `wiki-cli generate -u https://github.com/... -p -r 2` |
| `browse` | 在浏览器中预览已生成的 Wiki | 无参数 | `wiki-cli browse` |
| `ai` | 与 LLM 交互式问答，针对代码库提问 | `question`, `-C/--dir`, `-u/--url`, `--session`, `--list-sessions`, `--answer-only` | `wiki-cli ai "这个项目用了什么框架？"` |

所有命令都在 `src/cli.ts` 中通过 `program.command(...)` 注册，每个命令绑定到一个独立的 action 处理器：

```typescript
program
  .command('config')
  .description('Interactive configuration of LLM provider, model, API key, language')
  .option('--provider <provider>', 'LLM provider name')
  // ...
  .action(async (options) => { await configCommand(options); });
```

## 为什么聚焦 LLM 驱动的自动化文档生成？

传统的文档工具（如 JSDoc、Typedoc、Sphinx）只能从代码注释中提取文本，它们看不懂业务逻辑，也无法"理解"一个模块的用途。结果是：**注释写得多好，文档才有多好**——而写注释本身就是最大的瓶颈。

wiki-cli 的思路不同：它把**理解代码**这件事委托给 LLM。工具只负责三样事：

1. **文件系统探索**：读取目录结构、文件内容、Git 日志（通过[工具系统：LLM 只读探索工具的设计](工具系统-llm-只读探索工具的设计.md)提供的 8 个只读工具）
2. **文本编排**：将 LLM 返回的内容组织成 Markdown 文件
3. **进度与容错**：支持[断点续传](断点续传与并行生成策略.md)、并行生成、失败重试

这种分工让 LLM 发挥它的长处（理解自然语言和代码逻辑），同时让工具保持轻量和可靠。

## 目标用户与适用场景

| 用户类型 | 痛点 | wiki-cli 的价值 |
|---|---|---|
| **独立开发者 / 小型团队** | 人手少，文档总是被推迟 | 一键生成，零写作文档的时间成本 |
| **开源项目维护者** | 不想花大量精力写 Wiki，但需要好的 onboarding 文档 | 自动分析仓库结构，LLM 生成清晰的项目概览 |
| **接手遗留代码的开发者** | 项目没有文档，代码结构不熟悉 | 先用 `generate` 生成一份骨架，再用 `ai` 命令追问具体模块 |
| **技术写作者** | 需要快速了解一个项目的架构，作为写作起点 | 生成的 Wiki 可以作为初稿，在此基础上润色 |

如果你只是想在本地试试，5 分钟就能跑通，参见[快速开始](快速开始.md)。

## 架构一览

```
src/
├── cli.ts                  # CLI 入口，注册四条命令
├── commands/               # 每条命令的具体实现
│   ├── config.ts           # 配置命令
│   ├── generate.ts         # 生成管线
│   ├── browse.ts           # 本地 HTTP 服务器
│   └── ai.ts               # AI 交互式问答
├── ai/                     # LLM 相关核心
│   ├── llm-client.ts       # OpenAI 兼容客户端（流式 + 重试）
│   ├── tools.ts            # 8 个只读探索工具
│   ├── prompts.ts          # 提示词模板引擎
│   └── ai-session.ts       # 会话管理
├── utils/                  # 通用工具
│   ├── file.ts             # 文件系统工具集
│   ├── git.ts              # Git 克隆与更新
│   ├── workspace.ts        # 工作区管理
│   └── progress.ts         # 进度显示与日志
└── config/                 # 配置持久化
    ├── config-store.ts
    └── default-models.json # 7 大提供商模型列表
```
