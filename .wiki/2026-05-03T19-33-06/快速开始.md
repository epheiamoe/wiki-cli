# 快速开始

10 分钟内，你会亲手走完安装、配置、生成、浏览的完整闭环。我们将**用 wiki-cli 自身作为演示项目**——克隆仓库后，用它生成自己的文档。

---

## 第一步：安装

确保 Node.js ≥ 18，然后全局安装：

```bash
npm install -g wiki-cli
```

验证安装：

```bash
wiki-cli --version
```

你应该看到：

```
1.0.0
```

如果不想全局安装，也可以用 `npx` 直接运行：

```bash
npx wiki-cli --help
```

[来源](package.json#L5-L7)

---

## 第二步：克隆演示仓库

在你本地找一个工作目录，克隆 wiki-cli 的源码仓库：

```bash
git clone https://github.com/your-username/wiki-cli.git
cd wiki-cli
```

> 这个仓库本身就是一个结构清晰的 TypeScript 项目，非常适合作为首体验的对象。

---

## 第三步：配置 LLM 提供商

`wiki-cli config` 会启动一个交互式向导，引导你完成配置。

在项目根目录执行：

```bash
wiki-cli config
```

你会依次看到以下交互提示：

```
? Select LLM provider: (Use arrow keys)
❯ OpenAI
  Google Gemini
  Anthropic
  xAI Grok
  DeepSeek
  Kimi (Moonshot)
  Mistral
  ✏️  Custom (enter manually)
```

选择一个提供商（例如 DeepSeek），然后选择模型：

```
? Select model for DeepSeek:
❯ deepseek-v4-pro - DeepSeek V4 Pro (High quality, competitive price)
  deepseek-v4-flash - DeepSeek V4 Flash (Fast, cost-effective)
```

输入你的 API Key（输入时会被 `*` 遮蔽）：

```
? Enter API Key: [***********************]
```

选择文档语言：

```
? Documentation language (zh/en, default zh): zh
```

配置完成后你会看到成功提示：

```
✔ Configuration saved to C:\Users\你的用户名\.wiki-cli\config.json
```

你也可以通过命令行参数一步完成配置，参见[配置你的 LLM 提供商](配置你的-llm-提供商.md)。

[来源](src/commands/config.ts#L8-L105)

## 第四步：生成 Wiki 文档

确保你仍在 `wiki-cli` 项目根目录，执行：

```bash
wiki-cli generate
```

生成过程分为两个阶段，你会实时看到进度：

**阶段一：生成大纲**

```
ℹ Phase 1: Analyzing repository and generating outline...
```

LLM 会通过**函数调用**（Function Calling）读取仓库中的文件，理解项目结构，然后输出一份结构化的文档大纲。你可以在终端看到 LLM 流式输出的思考和工具调用日志：

```
ℹ LLM round 1 (streaming below)...
🔧 list_directory -> { path: "." }
📎 list_directory result: [".git", "src", "tests", ...]
🔧 read_file -> { path: "package.json" }
📎 read_file result: { content: "{\n  \"name\": \"wiki-cli\"..." }
...
✔ Generated 15 topics.
```

**阶段二：生成页面**

```
ℹ Phase 2: Generating Wiki pages...

? Generate pages in parallel? (faster, no streaming output) (y/N) n
```

选择 `n`（顺序生成，可以看到每个页面的流式输出），你会看到：

```
[1/15] Generating: 概览 (初学)
[流式输出内容...]
✔ Generated: 概览

[2/15] Generating: 快速开始 (初学)
[流式输出内容...]
✔ Generated: 快速开始
...
```

全部页面生成完毕后，终端会显示：

```
✔ Wiki generated at .wiki/2025-01-15T14-30-00
✔ Index file generated.
```

每个生成的 Wiki 版本会存储在 `.wiki/<时间戳>/` 目录下，生成过程中如果中断，重新运行 `wiki-cli generate` 会询问你是否继续，详情见[断点续传与并行生成](断点续传与并行生成.md)。

[来源](src/commands/generate.ts#L26-L97)

---

## 第五步：浏览 Wiki

生成完成后，一行命令即可在浏览器中查看结果：

```bash
wiki-cli browse
```

终端会显示：

```
ℹ Browsing Wiki: 2025-01-15T14-30-00
✔ Wiki server started at http://localhost:3000
```

浏览器会自动打开，你会看到一个带有**侧边栏导航**的 Wiki 页面：

- 左侧：目录树，按章节分组，每页标题前有难度标识（🟢 初学 / 🟡 中级 / 🔴 高级）
- 右侧：Markdown 渲染内容，支持代码语法高亮

点击侧边栏中的任意页面标题，右侧内容区会切换显示对应的文档。页面底部还提供了**历史版本**切换功能，可以回顾不同生成结果。

[来源](src/commands/browse.ts#L16-L71)

## 你刚完成了什么

| 步骤 | 命令 | 成果 |
|------|------|------|
| 1 | `npm install -g wiki-cli` | 安装 CLI 工具 |
| 2 | `git clone ... && cd wiki-cli` | 准备演示项目 |
| 3 | `wiki-cli config` | 配置 LLM 连接信息 |
| 4 | `wiki-cli generate` | 生成完整的 Wiki 文档 |
| 5 | `wiki-cli browse` | 在浏览器中浏览 Wiki |

全程约 5-10 分钟（取决于 LLM 响应速度），你已经用 wiki-cli 为 **它自己** 生成了完整的开发文档。
