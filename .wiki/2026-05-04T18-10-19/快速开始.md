# 快速开始

5 分钟从零到拥有一份 AI 生成的代码 Wiki。你只需要一个终端和一颗 API Key。

---

## 安装

```bash
npm install -g wiki-cli
```

安装后验证：

```bash
wiki-cli --version
# 输出：1.0.0
```

全局安装的 `wiki-cli` 命令通过 `package.json` 的 `bin` 字段注册——安装时 npm 自动将 `dist/cli.js` 链接到系统 PATH 中，之后在任何目录下都能直接调用。

> **系统要求**：Node.js >= 18，因为项目使用 ESM 模块（`"type": "module"`）。

[来源](package.json#L5-L8)

## 第一步：配置 LLM

wiki-cli 需要一个大语言模型（LLM）来分析和撰写文档。运行：

```bash
wiki-cli config
```

你会看到一个交互式菜单：

```
? What do you want to configure?
  LLM (provider / model / API key)
  Embedding (semantic search model)
  Web Fetch (let AI read documentation URLs)
❯ Both
  Done, quit
```

选择 **LLM**，然后依次：

1. **选择 Provider** — 支持 OpenAI、DeepSeek、Anthropic、Google Gemini、xAI Grok、Kimi、Mistral 等，选完后会展示该厂商的模型列表
2. **选择模型** — 每个模型附有简要说明和定价提示
3. **输入 API Key** — 密文输入，不会显示在屏幕上
4. **文档语言** — 输入 `zh`（中文）或 `en`（英文）

配置保存在 `~/.wiki-cli/config.json`，一次配好，后续生成自动加载。

[来源](src/commands/config.ts#L10-L40) | [来源](src/config/config-store.ts#L49-L52)

### 跳过交互式（高级）

如果你已经知道要用的参数，一步到位：

```bash
wiki-cli config \
  --provider DeepSeek \
  --model deepseek-chat \
  --api-key sk-xxxxxxxx \
  --lang zh
```

## 第二步：生成 Wiki

进入你的项目目录（必须是 Git 仓库），运行：

```bash
wiki-cli generate
```

生成分两个阶段，控制台实时输出进度：

```
ℹ Phase 1: Analyzing repository and generating outline...
ℹ Phase 1 / Round 1 (streaming below)...
✓ Outline generated successfully.
✓ Generated 12 topics.

ℹ Phase 2: Generating Wiki pages...
? Generate pages in parallel? (faster, no streaming output) (y/N)
```

### Phase 1：生成大纲

AI 自动分析项目结构（目录、文件、代码），生成一份 JSON 格式的大纲，包含所有 Wiki 页面的标题、难度级别和写作任务。大纲保存在 `.wiki/temp/_outline.json`。

[来源](src/commands/generate.ts#L155-L190)

### Phase 2：生成页面

AI 根据大纲逐页撰写 Markdown 文档。系统会问你是否用 **并发生成**（`--parallel`）——开启后速度提升 3-5 倍，适合大型项目。

如果生成中断（网络问题或 Ctrl+C），再次运行 `wiki-cli generate` 会自动检测暂存数据，询问是否**断点续传**：

```
? Previous generation temp data found. What do you want to do?
  🔄 Resume from last checkpoint
  🗑️  Discard and start fresh
```

[来源](src/commands/generate.ts#L72-L80)

### 可选参数

| 参数 | 用途 |
|------|------|
| `--url <git-url>` | 从远程仓库克隆后生成 |
| `-b, --branch <name>` | 指定分支 |
| `--parallel -c 5` | 并发生成，5 个并发 |
| `-o, --output <path>` | 输出到自定义目录 |
| `--browse` | 生成后自动打开浏览器 |
| `--silent` | 静默模式，全自动 |

[来源](src/cli.ts#L57-L83)

## 第三步：浏览 Wiki

生成完成后，终端会询问是否打开浏览器：

```
✓ Wiki generated at /your-project/.wiki/20251231_235959
? Wiki 已生成于 ...，打开浏览器查看？ (Y/n)
```

选 Yes，或手动运行：

```bash
wiki-cli browse
```

内置 HTTP 服务器自动启动并在默认浏览器中打开：

```
✓ Wiki server started at http://localhost:3000
```

### 浏览器界面

页面分为两栏：

- **左侧边栏**：导航目录，每个条目带难度标记 🟢 初学 / 🟡 中级 / 🔴 高级
- **右侧内容区**：渲染后的 Markdown 文档，支持：
  - **代码高亮** — 基于 highlight.js
  - **Mermaid 图表** — 流程图、时序图自动渲染
  - **源代码跳转** — `[来源：src/commands/config.ts#L10-L20]` 点击在新标签页打开带行号高亮的源码
  - **历史版本切换** — 点击右上角"历史版本"可查看之前生成的 Wiki 版本

服务器默认从 3000 端口开始，如果被占用自动递增寻找空闲端口。

[来源](src/commands/browse.ts#L64-L74) | [来源](src/commands/browse.ts#L210-L223)

## 项目结构说明

生成完成后，项目目录下会出现 `.wiki/` 文件夹：

```
your-project/
├── .wiki/
│   ├── 20251231_235959/          # ← 时间戳命名的版本目录
│   │   ├── index.json            # 索引文件，定义导航结构和页面元信息
│   │   ├── project-architecture.md
│   │   ├── 快速开始.md
│   │   ├── cli入口与命令体系.md
│   │   └── ...                   # 所有 Wiki 页面（Markdown）
│   ├── 20251230_120000/          # 之前生成的版本
│   │   └── ...
│   ├── temp/                     # 生成过程中的临时数据
│   └── sessions/                 # AI 问答会话记录
```

### index.json 的作用

`index.json` 是 Wiki 的"目录文件"，browse 服务器用它来渲染侧边栏导航。结构如下：

```json
{
  "sections": [
    {
      "name": "项目基础",
      "topics": [
        { "level": "初学", "title": "快速开始", "description": "5 分钟完成安装配置" },
        { "level": "中级", "title": "CLI入口与命令体系", "description": "命令注册和分发机制" }
      ]
    },
    {
      "name": "高级功能",
      "topics": [
        { "type": "group", "title": "AI 功能" },
        { "level": "高级", "title": "LLM客户端设计", "description": "流式客户端实现" }
      ]
    }
  ]
}
```

每个版本目录下的 `index.json` 定义了该版本的完整导航结构，browse 服务器会按 `index.json` 构建侧边栏，按 section 分组并显示难度标记。[来源](src/commands/generate.ts#L283-L307)

每个版本还附带 `.meta.json` 记录生成时的 Git 信息：

```json
{
  "generatedAt": "20251231_235959",
  "gitCommit": "a1b2c3d...",
  "gitBranch": "main",
  "gitRemote": "https://github.com/user/repo.git"
}
```
