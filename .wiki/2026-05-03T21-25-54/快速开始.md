# 快速开始

从零开始，5 分钟内体验 wiki-cli 的完整工作流：安装工具 → 配置 LLM → 生成 Wiki → 浏览器浏览。

## 前提条件

使用本工具前，你需要准备以下两项：

- **Node.js 18+** —— 运行环境和包管理器 npm 的基础。
- **一个 LLM 的 API Key** —— 如果没有，推荐注册 **DeepSeek**（`platform.deepseek.com`），新用户注册即送免费额度，无需绑定付费方式即可完成本次体验。

## 第一步：安装

在终端执行全局安装：

```bash
npm install -g wiki-cli
```

安装完成后，验证是否成功：

```bash
wiki-cli --help
```

预期输出：

```
Usage: wiki-cli [options] [command]

Auto-generate structured Wiki documentation for any local code repository

Options:
  -V, --version      output the version number
  -h, --help         display help for command

Commands:
  config [options]   Interactive configuration of LLM provider, model, API key, language
  generate           Analyze current repository and generate Wiki documentation
  browse             Open generated Wiki in browser
  ai [options]       Interactive AI chat about the codebase
```

看到四条命令说明安装成功。[来源](cli.ts#L1-L82)

如果不想全局安装，也可以使用 `npx wiki-cli` 直接运行。

## 第二步：配置

配置是 wiki-cli 和 LLM 之间的"握手"环节。你需要告知工具使用哪家 LLM、哪个模型、以及你的 API Key。

运行交互式配置命令：

```bash
wiki-cli config
```

程序会依次弹出四个交互问题。以下是用 **DeepSeek** 配置的完整流程，你将看到的选择界面如下（你的版本可能略有不同）：

```
? Select LLM provider: (Use arrow keys)
  OpenAI
  Google Gemini
  Anthropic
  xAI Grok
❯ DeepSeek
  Kimi (Moonshot)
  Mistral
  ✏️  Custom (enter manually)
```

选择 **DeepSeek** 后进入模型选择：

```
? Select model for DeepSeek: (Use arrow keys)
  deepseek-v4-pro - DeepSeek V4 Pro (High quality, competitive price)
❯ deepseek-v4-flash - DeepSeek V4 Flash (Fast, cost-effective)
```

选择 `deepseek-v4-flash`（免费、快速、性价比高）。接着输入你的 API Key（输入内容被掩码保护）：

```
? Enter API Key: [****************************************]
```

最后设置文档语言（直接回车使用默认值 `zh`）：

```
? Documentation language (zh/en, default zh): zh
```

配置完成后，看到以下绿色提示表示保存成功：

```
✔ Configuration saved to C:\Users\<用户名>\.wiki-cli\config.json
```

配置文件内容大致如下：

```json
{
  "provider": "DeepSeek",
  "baseUrl": "https://api.deepseek.com",
  "model": "deepseek-v4-flash",
  "apiKey": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "lang": "zh"
}
```

**参数说明：**

| 参数 | DeepSeek 典型值 | 说明 |
|------|----------------|------|
| `baseUrl` | `https://api.deepseek.com` | API 端点，自动填充 |
| `model` | `deepseek-v4-flash` | 免费模型，适合初次体验 |
| `apiKey` | `sk-...` | DeepSeek 官网申请 |

如果想跳过交互模式，也可以一步到位：

```bash
wiki-cli config --provider DeepSeek --base-url https://api.deepseek.com --model deepseek-v4-flash --api-key sk-你的密钥 --lang zh
```

更多配置选项请参阅 [配置命令：wiki-cli config](配置命令-wiki-cli-config.md) 和 [LLM 提供商与模型选择](llm-提供商与模型选择.md)。[来源](commands/config.ts#L1-L110)

## 第三步：生成

配置完成之后，用 `cd` 进入你想生成文档的任意本地代码仓库目录，然后运行：

```bash
wiki-cli generate
```

生成过程分为两个阶段：

### 阶段 1：生成大纲

工具会使用 LLM 分析你的仓库目录结构，经多轮"对话-工具调用"迭代，最终产出一份 JSON 格式的文档大纲。终端输出类似：

```
ℹ Phase 1: Analyzing repository and generating outline...
ℹ LLM round 1 (streaming below)...
Thinking: 让我先了解这个仓库的结构...
[工具调用] - list_directory
[工具调用] - list_files
[工具调用] - read_file: package.json
[工具调用] - ...更多工具调用...
✔ Outline generated successfully.
✔ Generated 12 topics.
```

这个过程中，LLM 会调用 `list_directory`、`list_files`、`read_file` 等只读工具来探索代码库，**不会修改任何代码**。详细的执行机制请阅读 [大纲生成阶段](大纲生成阶段.md)。[来源](commands/generate.ts#L72-L155)

### 阶段 2：生成页面

大纲生成后，程序会询问你的生成模式：

```
? Generate pages in parallel? (faster, no streaming output) (y/N)
```

如果选择 **否**（默认），工具会逐个生成每个页面，并**实时流式输出**每页的 Markdown 内容到终端——你可以亲眼看着文档一页页"写出来"：

```
ℹ [1/12] Generating: 整体架构与模块划分 (中级)
# 整体架构与模块划分
...
✔ Generated: 整体架构与模块划分

ℹ [2/12] Generating: CLI 入口点与命令注册 (初学)
# CLI 入口点与命令注册
...
✔ Generated: CLI 入口点与命令注册
```

如果选择 **是**，则启用并行模式（默认 3 个并发），速度更快但不在终端显示实时内容。

所有页面生成完毕后，临时目录会被移动到带时间戳的最终目录：

```
✔ Wiki generated at .wiki/2024-01-15T14-30-22
✔ Index file generated.
```

如需深入了解生成流程，请参阅 [生成命令：wiki-cli generate](生成命令-wiki-cli-generate.md)。[来源](commands/generate.ts#L30-L70)

## 第四步：浏览

生成完成后，在同一目录下运行：

```bash
wiki-cli browse
```

终端输出：

```
✔ Wiki server started at http://localhost:3000
```

**默认浏览器会自动打开**该地址，你将看到：

```
┌─────────────────────────────────────────────────────────┐
│ 📖 Wiki                    [历史版本]                    │
│ ┌─────────────────┐  ┌────────────────────────────────┐│
│ │ 🟡 整体架构与模块划分│  │ # 整体架构与模块划分         ││
│ │ 🟢 快速开始        │  │                              ││
│ │ 🟢 配置命令        │  │ [正文内容...]                 ││
│ │ 🟡 生成命令        │  │                              ││
│ │ 🟢 浏览命令        │  │                              ││
│ │ 🟡 LLM 提供商      │  └────────────────────────────────┘│
│ │ ...              │                                     │
│ └─────────────────┘                                       │
└─────────────────────────────────────────────────────────┘
```

- **左侧导航栏**：显示所有文档页面，按章节分组。🟢 标识初学、🟡 中级、🔴 高级。
- **右侧内容区**：渲染后的 Markdown 文档，代码块带语法高亮（暗色主题）。
- **右上角"历史版本"按钮**：点击可切换不同时间生成的 Wiki 版本。

点击左侧任意页面标题，右侧自动切换内容，浏览器地址栏也会同步更新为 `#页面-slug`。

浏览机制详细说明请查阅 [浏览命令：wiki-cli browse](浏览命令-wiki-cli-generate.md) 和 [HTTP 服务与前端渲染](http-服务与前端渲染.md)。[来源](commands/browse.ts#L1-L130)

## 常见问题排除

### 安装失败：权限不足

**症状**：`npm install -g` 报 EACCES 或权限错误。

**解决**：Windows 用户建议以管理员身份运行终端；macOS/Linux 用户可使用 `npx wiki-cli` 代替全局安装。

### 配置后生成仍报错 "No configuration found"

**症状**：运行 `wiki-cli generate` 后提示没有配置。

**原因**：配置文件保存到用户主目录（`~/.wiki-cli/config.json`），如果在不同终端窗口运行配置和生成，请确保使用同一用户。

**验证**：运行 `wiki-cli config` 并直接退出，看能否看到已保存的配置项。

### DeepSeek API 连接失败

**症状**：生成阶段卡住或报 API 错误。

**检查项**：
- API Key 是否有效（登录 DeepSeek 官网验证）
- 网络是否能访问 `api.deepseek.com`（部分网络环境需代理）
- baseUrl 是否正确：`https://api.deepseek.com`

### 生成过程中断

**症状**：生成到一半终端被关闭或网络断开。

**解决**：重新运行 `wiki-cli generate`，工具会自动检测之前的临时文件（`.wiki/temp/`），并询问是否从中断处恢复：

```
? Previous generation temp data found. What do you want to do?
  🔄 Resume from last checkpoint
  🗑️  Discard and start fresh
```

选择 **Resume** 即可继续。详细机制请参阅 [断点续传与重试机制](断点续传与重试机制.md)。[来源](commands/generate.ts#L38-L47)
