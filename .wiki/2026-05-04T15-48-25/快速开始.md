# 快速开始

5 分钟，从零到一完成 wiki-cli 的安装、配置、生成与浏览。你需要一个 AI 模型的服务商 API Key（如 DeepSeek、OpenAI 等），其余都由命令行搞定。

---

## 第一步：安装

确保你的环境已安装 **Node.js >= 18**，然后全局安装：

```bash
# 全局安装，安装后即可使用 wiki-cli 命令
npm install -g wiki-cli

# 验证安装成功
wiki-cli --version
# 预期输出: 1.0.0
```

> 如果不用全局安装，也可以在项目目录中 `npm install wiki-cli`，然后用 `npx wiki-cli` 替代 `wiki-cli`。

安装完成后，`wiki-cli` 命令便可在终端中使用。所有子命令通过 Commander.js 注册调度。

## 第二步：配置

> **前提**：你需要一个 LLM 服务商的 API Key。如果还没有，去 DeepSeek、OpenAI 或你选择的提供商注册获取。

执行交互式配置向导：

```bash
wiki-cli config
```

你将看到一个清晰的选择菜单，完整流程如下（带注释）：

```text
? What do you want to configure? (用方向键选择)
  LLM (provider / model / API key)       ← 只配大模型
  Embedding (semantic search model)       ← 只配语义搜索（可选）
  Web Fetch (let AI read documentation URLs)  ← 只配网页抓取（可选）
❯ Both                                    ← 推荐选 Both，一步到位
  Done, quit

# --- 以下为 Both 路径的交互过程 ---

? Select LLM provider:
  OpenAI
  DeepSeek
  Anthropic
  Google Gemini
  xAI Grok
  Kimi (Moonshot)
  Mistral
❯ ✏️  Custom (enter manually)

? Select model for DeepSeek:              ← 选择具体模型
  deepseek-v4-pro - DeepSeek V4 Pro (High quality, competitive price)
❯ deepseek-v4-flash - DeepSeek V4 Flash (Fast, cost-effective)

? Enter API Key: [*******************]   ← 输入你的 API Key（密文显示）

? Documentation language (zh/en, default zh):
  zh                                     ← 文档语言，默认中文
```

预期输出：

```text
✔ Configuration saved to C:\Users\你的用户名\.wiki-cli\config.json
```

配置文件保存在用户主目录下的 `.wiki-cli/config.json`，**一次配置，全局生效**。

[来源](src/commands/config.ts#L10-L13)

### 纯参数模式（跳过交互）

如果你已经知道所有参数，一行搞定：

```bash
wiki-cli config \
  --provider DeepSeek \
  --model deepseek-v4-flash \
  --api-key sk-xxxxxxxxxxxxxxxx \
  --lang zh
```

可用的参数选项：

| 选项 | 作用 |
|------|------|
| `--provider <name>` | 提供商名称，如 DeepSeek、OpenAI |
| `--model <name>` | 模型名称 |
| `--api-key <key>` | API Key |
| `--base-url <url>` | 自定义 API 地址（可选） |
| `--lang <zh/en>` | 文档语言 |
| `--llm-only` | 只配置 LLM |
| `--embedding-only` | 只配置 Embedding |

四个核心参数同时传入便会跳过交互、直接保存。

## 第三步：生成 Wiki

在项目的根目录（必须是 **Git 仓库**）中执行：

```bash
wiki-cli generate
```

工具会先分析仓库结构和代码，然后让 LLM 生成大纲，最后逐页撰写文档。你会看到以下输出：

```text
✔ Phase 1: Analyzing repository and generating outline...
  Phase 1 / Round 1 (streaming below)...
  <AI 在这里实时输出分析过程、列出目录结构、阅读关键文件...>

✔ Generated 12 topics.

✔ Phase 2: Generating Wiki pages...
  [1/12] Generating: 项目架构全景 (中级)
  <AI 逐字输出页面内容...>
✔ Generated: 项目架构全景

  [2/12] Generating: 快速开始 (初学)
  <AI 逐字输出...>
✔ Generated: 快速开始
  ...

✔ Wiki generated at C:\Users\xxx\project\.wiki\20250315_123045
✔ Index file generated.

? Wiki 已生成于 C:\Users\xxx\project\.wiki\20250315_123045，打开浏览器查看？ (Y/n)
```

### 生成过程的两阶段

| 阶段 | 耗时 | 做什么 |
|------|------|--------|
| Phase 1：大纲 | 约 30-60 秒 | LLM 读取仓库结构，输出结构化的 JSON 大纲 |
| Phase 2：页面 | 约 2-10 分钟 | 按照大纲逐个生成 Markdown 页面 |

生成的 Wiki 默认输出到 `.wiki/` 目录下，以时间戳（如 `20250315_123045`）为子目录名，每次生成都是一个独立版本。

### 常用参数加速

```bash
# 并发生成（快 3-5 倍）
wiki-cli generate --parallel -c 5

# 生成完自动打开浏览器
wiki-cli generate --browse

# 全自动模式：不询问，直接生成 + 浏览
wiki-cli generate --silent --parallel --browse

# 从远程仓库生成
wiki-cli generate --url https://github.com/user/repo.git
```

## 第四步：浏览

生成完成后，使用内置的 HTTP 服务器浏览 Wiki：

```bash
wiki-cli browse
```

预期输出：

```text
✔ Wiki server started at http://localhost:3000
```

浏览器会自动打开，你将看到：

```text
┌─────────────────────────────────────────────────────────┐
│  📖 Wiki                          [历史版本]            │
│  ───────────────────────                                 │
│  🟢 概览                                                 │
│  🟢 快速开始                                             │
│  🟡 生成命令详解                                         │
│  🔴 LLM 客户端设计                                       │
│     ...                                                  │
│                                         ┌──────────────┐│
│                                         │ 渲染后的      ││
│                                         │ Markdown 内容 ││
│                                         │              ││
│                                         │ 代码高亮     ││
│                                         │ Mermaid 图表 ││
│                                         └──────────────┘│
└─────────────────────────────────────────────────────────┘
```

浏览器的核心功能：

- **左侧导航栏**：按章节组织的页面列表，难度标记为 🟢 初学 / 🟡 中级 / 🔴 高级
- **右侧内容区**：Markdown 渲染为精美页面，代码自动高亮，Mermaid 图表自动渲染
- **源码跳转**：文中 `[来源：src/commands/generate.ts#L23-L69]` 这类标记，点击即可在新标签页中查看源码（带行号高亮）
- **历史版本**：右上角可切换不同时间戳生成的版本

如果想指定目录或查看远程仓库的缓存 Wiki：

```bash
# 指定路径
wiki-cli browse --path /path/to/project

# 查看之前用 --url 生成的远程仓库 wiki
wiki-cli browse --url https://github.com/user/repo.git
```

## 第五步（可选）：AI 问答

Wiki 生成后，你还可以直接用自然语言向 AI 提问代码库：

```bash
# 进入交互模式，持续对话
wiki-cli ai

# 或一次性提问
wiki-cli ai "这个项目的架构是怎么样的？"
```

AI 会调用工具读取源码、搜索 Wiki，每一步都可见：

```text
🔧 Tool: list_directory
  ↳ Result: [...]
🔧 Tool: read_file
  ↳ Result: ...
💬 回答：这个项目的架构分为四层：CLI 入口层...
```
